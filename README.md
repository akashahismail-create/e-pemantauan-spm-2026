# E-Pemantauan SPM & Amali Sains 2026
Jabatan Pendidikan Negeri Selangor

## 2 Jenis Pemantauan
1. Pemantauan untuk SPM - 504 Pusat
2. Pemantauan untuk Ujian Amali Sains - 473 Makmal

## Features
- Nama Sekolah filter No Pusat auto
- Tarikh validation: "Tarikh yang dipilih tidak sepadan dengan jadual waktu"
- Calon Berdaftar, Hadir, Tidak Hadir = Berdaftar - Hadir, Keseluruhan = Berdaftar + Cicir + Bantah
- Jawatan: Penolong Pengarah SPP (JPN 11 orang) & Penolong PPD SPP (PPD 24 orang)
- One Page Report cantik bergambar (Dewan & Sekolah tanpa bendera)
- Tanpa sidebar, borang bersih

## Run Local
```
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Cloud
1. Upload ke GitHub
2. Deploy di share.streamlit.io
